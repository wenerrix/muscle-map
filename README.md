# 全身肌群地圖 Muscle Map

一個單頁網站，用來系統性了解全身肌群和對應的訓練動作，並安排自己的訓練。

## 功能

- **恢復狀態**：依照訓練紀錄把全身肌肉上色（紅＝恢復中、黃＝快恢復、綠＝可以練），並建議今天練哪些部位，一鍵帶入課表。
- **肌群地圖**：點正面、背面全身圖上的 21 個肌群，看放大圖、功能和對應動作。
- **今天練什麼**：選部位和時間，產生照順序做的課表。
- **訓練模式**：在課表、一週菜單或特別計畫按「▶ 開始」，進入全螢幕訓練：一次一個動作、記錄每組、完成後自動開始休息計時、保持螢幕不熄滅，最後顯示訓練總結。
- **一週菜單**：每週 3 天（全身）、4 天（上下半身）、5 天（推拉腿＋上下半身）三種排法。
- **特別計畫**：寬肩、塞滿袖口兩個 7 週計畫。
- **飲食教練**：依身高、體重、活動量和目標，算出熱量、蛋白質、碳水、脂肪，並產生每天自動輪換的菜單：每餐的菜色和份量都依照你的目標換算，可以單獨換一道、整天換一組、往前往後看不同天，還有當天的採買清單。
- **動作圖庫**：67 個動作，每個都有中英文名稱、兩格動態示範圖和 YouTube 示範影片（彈出視窗裡的「YouTube 影片」分頁）。
- **訓練分頁**：每個動作的彈出視窗都有「訓練」分頁，可以記錄每組的重量和次數、用休息計時器（完成一組後自動開始）、看暖身組建議和歷史紀錄。紀錄存在瀏覽器的 localStorage，可以複製備份和還原。
- **器材選擇**：每個區塊都能切換器材（健身房、只有阻力繩、啞鈴＋阻力繩、只有徒手），課表會自動換成做得到的動作。

## 安裝成 App（離線可用）

GitHub Pages 版本可以安裝到手機或電腦，從主畫面全螢幕開啟，沒有網路時課表、紀錄、計時器和示範圖都能照常使用（YouTube 影片需要網路）。

- **Android／電腦 Chrome、Edge**：打開網站時會出現「安裝 App」按鈕，或從瀏覽器選單選「安裝應用程式」。
- **iPhone／iPad**：用 Safari 開啟，點「分享」→「加入主畫面」。

注意：iPhone 主畫面上的 App 和 Safari 的資料是分開存的，如果之前在 Safari 有訓練紀錄，請先在動作的「訓練」分頁用「複製全部紀錄」備份，再到 App 裡「還原備份」。

## 檔案

- `index.html`：整個網站（HTML、CSS、JavaScript 都在這個檔案裡）。
- `img/`：動作示範圖，每個動作 `-0.jpg`、`-1.jpg` 兩張。
- `manifest.webmanifest`、`icons/`：App 名稱、圖示和捷徑。
- `sw.js`：離線快取（service worker）。每次更新檔案後版本號會自動改變，安裝的 App 會收到新版本。

## 部署

這是純靜態網站，不需要 build。

- **GitHub Pages**：repo 的 Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`。
- **Netlify**：Add new site → Import an existing project → 選這個 repo，Build command 留空，Publish directory 填 `.`。
